# jpe-nix

Composable Nix flakes. Upstream defaults, your choices.

Small Nix flakes package upstream projects and expose declarative options for
Home Manager, NixOS, and macOS.

## Projects

- [nix-herdr](https://github.com/jpe-nix/nix-herdr): Nix packages and modules
  for the Herdr terminal workspace manager.
